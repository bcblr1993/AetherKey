# AetherKey

原生 macOS 中文拼音输入法，面向 Apple 芯片 Mac，支持 macOS 14 及以上。

[官网与下载](https://aethernative.com/apps/aetherkey/) · [使用帮助](https://aethernative.com/apps/aetherkey/support/) · [问题反馈](https://github.com/bcblr1993/AetherKey/issues)

## 功能

- 本机拼音转换、用户学习与自定义短语，无需账号。
- 候选面板跟随光标、宽度随内容调整，支持选词、翻页和展开。
- Unicode Unihan 17.0.0 字音补充：44,359 个有普通话读音的汉字，覆盖全部 8,105 个通用规范汉字。
- 中文 Emoji 关键词、智能标点、可选中英自动空格、V 模式计算和人民币大写。
- 1.0.1 起支持 Sparkle 应用内更新；支持全拼、小鹤双拼和微软双拼；暂无云同步、语音和手写。

## 安装

从 GitHub Release 或官网下载 DMG，打开「安装 AetherKey.app」并按向导操作。
在系统设置 → 键盘 → 文本输入 → 编辑中添加「AetherKey 拼音」，再从菜单栏切换。
若未立即列出，请注销并重新登录。

输入法安装到 `~/Library/Input Methods/AetherKey.app`。
用户词库位于 `~/Library/Application Support/AetherKey/user_lexicon.json`；更新保留词库。
先切换到其他输入法再移除 AetherKey；用户词库不会随卸载自动删除。

## 应用内更新

从输入法菜单或设置「更新与启动」中的「检查更新」进入；自动检查默认每 6 小时一次，可在设置中关闭。更新归档只包含输入法本体，使用 Ed25519 验证后安装并重新启动，保留个人词库与偏好。1.0.0 用户需要手动安装一次当前版本；1.0.1 及以上可直接应用内更新。支持登录后自动启动，设置页显示 macOS 实际注册状态。

Sparkle 2.10.0 使用 MIT 许可；完整许可随安装包提供。发布密钥保存在 macOS 钥匙串 `AetherKey` 账户中，不进入仓库。

## 构建与验证

使用 Xcode，打开 `AetherKey.xcodeproj`。项目配置同时保存在 `project.yml`。

```sh
xcodebuild -project AetherKey.xcodeproj -scheme AetherKey -configuration Debug test
xcodebuild -project AetherKey.xcodeproj -scheme AetherSetup -configuration Release build
```

正式发布：`scripts/release.sh`。需要有效的 Developer ID Application 身份与 Notarytool Keychain profile；通过 `SIGN_IDENTITY`、`NOTARY_PROFILE` 和 `RELEASE_OUT` 指定。该脚本按嵌套顺序签名、公证并装订票据，再生成签名公证 DMG。

字音数据可用 `scripts/build_character_lexicon.py` 从固定 SHA256 的 Unihan 17.0.0 压缩包重新生成。Unicode 数据许可随资源提供：`Resources/Unihan-LICENSE.txt` 与 `Resources/Unicode-LICENSE.txt`。源码公开供审阅；未另行声明开放源代码许可证。

### 拼音编辑与候选管理

- 通用设置可开启「四方向键选择候选」（默认关闭）：`← / ↑` 选择上一个，`→ / ↓` 选择下一个，空格确认；`Option + ← / →` 仍按音节移动拼音光标。
- 未开启时，`← / →` 在拼音串内移动，`Option + ← / →` 按音节移动，`Home / End` 到开头或末尾。
- `Delete` 删除光标前一个字母，`Option + Delete` 删除前一个音节，向前删除键删除光标后的字母。
- `↑ / ↓ / Tab / Shift + Tab` 选择候选，空格上屏，`- / =` 翻页。
- 右键候选词可置顶、取消置顶或忘记；键盘对应 `Control + Option + P / U / Delete`，作用于当前高亮词。
- 置顶与忘记按拼音分别保存，忘记会移除该拼音下的学习、自定义和置顶记录，并隐藏同名候选。需要恢复时，可在词库中心重新添加该拼音和短语。
- 整句组词保留多条词组组合，结合词典顺序、词组完整度与本机选词记录排序；不使用联网语言模型。

1.0.5 新增默认关闭的“四方向键选择候选”：开启后四个箭头都能选词，Option + 左右键保留拼音编辑。保持自适应面板与光标跟随，54 项回归及 Mac mini 真实打字测试通过。

### 双拼方案

在「AetherKey 设置 → 通用设置 → 拼音方案」选择全拼、小鹤双拼或微软双拼，也可从输入法菜单切换。默认保留全拼；正在编辑的拼音保持原方案直到结束。

- 小鹤：`nihc` → 你好、`vsgo` → 中国、`jbtmtmqi` → 今天天气。
- 微软：`nihk` → 你好、`vsgo` → 中国、`p;` → 平（`;` 是 ing）。零声母用 o，例如 `oa` → 啊、`or` → er（如二、而）。
- 支持中间编辑、按音节移动/删除、分段选词、翻页、右键置顶与忘记。学习和词库按标准拼音保存，三种方案共用。
- 双拼中 `v` 表示 zh；输入 `v` 加数字仍可使用计算器。回车提交原始按键，空格选词。

键位核对参考：[小鹤方案](https://github.com/rime/rime-double-pinyin/blob/master/double_pinyin_flypy.schema.yaml)、[微软方案](https://github.com/rime/rime-double-pinyin/blob/master/double_pinyin_mspy.schema.yaml)。

1.0.6 统一设置页的侧边导航、分组卡片与明暗外观，优化词库和快捷键展示；菜单栏采用圆角实心 A 字牌，保留 AetherKey 品牌名称。

### 五笔 86（1.0.7）

在「设置 → 通用设置 → 输入方案」选择「五笔 86」，也可从输入法菜单切换。默认仍为全拼，现有输入源名称保持不变；切换方案不改变正在编辑的编码。

- 支持一级、二级和三级简码、四码单字与词组。例如 `g` → 一、`wq` → 你、`vbg` → 好、`khlg` → 中国。
- 四码后空格选词；继续输入第五码时，确认当前高亮候选并开始下一字词。无码或正在中间编辑时不触发顶字，避免错误上屏。
- `z` 加拼音可反查汉字或词组及其五笔编码，如 `znihao` → 你好（wqvb）。反查只返回码表可编码的文字，不代表五笔覆盖全部 Unihan 汉字。
- 选词、翻页、四方向键开关、紧凑候选与光标跟随继续复用现有界面；Option + 左右键逐码编辑，回车提交原始编码，Esc 取消。
- `v` 是五笔字根，五笔模式不启用 V 模式计算器。切回全拼/双拼后仍可正常使用计算器。
- 词库中心可保存 1–4 码五笔自定义短语。学习、短语、置顶和忘记使用独立的 `wubi86:` 命名空间，与拼音偏好互不干扰。

码表来源为 [rime/rime-wubi](https://github.com/rime/rime-wubi/tree/152a0d3f3efe40cae216d1e3b338242446848d07)，原始 YAML 未修改，固定校验值、作者名单和 LGPL-3.0/GPL-3.0 许可随 `Resources/Wubi86` 提供；未链接 Rime 引擎。码表可作为独立资源编辑并重新构建。当前先支持 86 版，未包含 98 版和新世纪版。

### 键入纠错、整句防误拼与词库卫生治理（1.0.9）

- 实时键序纠错与整句防误拼：自动修正元音/鼻音倒置（如 `houmina → 后面`、`shijain → 时间`、`baozhneg → 保证`、`xinag → 想`、`xingnegn → 性能`）、双敲辅音（如 `shemme → 什么`、`rangnni → 让你`）、漏元音（如 `woshnme → 我什么`）及冗余鼻音尾缀（如 `gongzuong → 工作`），并杜绝将无关联单字或生僻鼻音独音字（`哽`、`鞥`）强行拼接成伪整句。
- 词库卫生与误上屏立撤回：单声母普通词频不再劫持默认高频首字（如 `w → 我`、`c → 此`）；拦截随机乱敲长串污染词频表；上屏后立即按 `Delete` 自动撤回刚刚记录的自学习词频与配对引号翻转状态。
- 偏好管理与交互细节：设置页「词库与短语」新增置顶与已忽略词条可视化管理面板（支持一键取消置顶与恢复候选）及短语搜索；修复 `[ / ]` 候选翻页快捷键、双拼常见缩写简拼兜底及失焦/退格后的中英混排上下文状态同步。

### 简繁转换、双拼扩展、竖排面板与按应用规则（1.1.0）

- **简繁转换与词库统一**：在通用设置、输入法菜单或按 `⌃⇧F` 随时切换简/繁体中文输出（输入过程中按 `⌃⇧F` 保留当前编码并原位刷新候选，弹窗胶囊显示「繁 / 简」状态）。基于系统 `Hans-Hant` 转换与 15 组一对多词组校对表（如 `回复→回覆`、`反复→反覆`、`复习→複習`、`手表→手錶`、`台风→颱風`），保留英文候选（`英`）、Emoji 与 V 模式内容不变；置顶、忽略、自学习词频与前文联想统一以规范文本保存，简繁体无缝共享个人词库。
- **双拼扩展与键位速查表**：新增「自然码双拼」与「搜狗双拼」（现共支持全拼、小鹤、微软、自然码、搜狗与五笔 86 六种输入方案），搜狗双拼同样支持分号 `;` 输入 `ing`；选择任意双拼方案时，设置页即时展示对应的 QWERTY 双拼键位速查表。
- **11 项细粒度模糊音**：模糊音设置支持按规则独立开关，覆盖平翘舌（`zh ↔ z`、`ch ↔ c`、`sh ↔ s`）、鼻边音与唇齿/卷舌音（`l ↔ n`、`f ↔ h`、`r ↔ l`，默认关闭）及前后鼻音（`an ↔ ang`、`en ↔ eng`、`in ↔ ing`、`ian ↔ iang`、`uan ↔ uang`）。
- **竖排面板、字号与每页候选数**：支持切换候选面板方向（横排 / 竖排，菜单亦可快速切换）、自定义每页候选数（`5–9` 个，横排双行模式自动显示 2 倍，竖排按所选数量逐行排列）与候选字号（设置页支持 `14–19 pt`，引擎支持 `13–22 pt` 范围自动适配行高与宽度）。
- **按应用自动中英文**：扩充内置终端与代码编辑器列表（新增 Xcode、Cursor、Zed、Windsurf、Sublime Text 4、VS Code Insiders、Tabby、Neovide、Rio 等），并在设置页与输入法菜单新增按应用自定义默认模式（可指定跟随全局、默认英文或默认中文；优先级为会话内手动 `Shift` 切换 > 自定义应用规则 > 内置终端/编辑器开关 > 默认中文）。
- **V 模式实用宏与普通中文数字**：新增 `vnow` / `vdt` / `vdatetime`（日期时间与 ISO 8601）、`vts` / `vtimestamp`（Unix 秒/毫秒时间戳）、`vuuid`（大小写随机 UUID）、`varrow` / `vjt`（箭头符号）、`vmath` / `vsx`（数学符号）、`vgreek` / `vxl`（希腊字母）与 `vfh` / `vfuhao` / `vsym`（常用符号）；输入非负整数（`0`–`999,999,999,999`）时追加小写中文数字候选（如 `v123` → `一百二十三`）。
- **问题修复与引擎优化**：
  - 修复盘古空格对 CJK 标点区段（`U+3000–U+303F`）的误判（不再在 `《AetherKey》`、`你好。Hello`、`Mac、iPad` 等标点旁插空格），并扩展汉字识别区段至 `U+20000–U+323AF`。
  - 修复 V 模式提交或 `Esc` 取消后 `inputMode` 未复位导致的智能标点与 `Shift` 异常，以及 `vdate` 等纯字母宏模式下按数字键 `1`–`9` 误追加数字而非直接选词的问题。
  - 修复大小写混排原始英文候选（`英`）通过数字键或点击选词时丢失大小写的问题（如 `iPhone`）。
  - 整句组词上限由 12 音节提升至 24 音节，局部前缀支持最多 5 音节并纳入个人词频；引入语料词频筛选同音次选（如 `我去山西`、`我想吃水饺`、`这个事件`）；增补 19 组零冲突纠错（如 `zhne → 真`、`yuo → 有`、`jui → 就`、`hau → 好`）；修复光标位于首部按退格键重置翻页、`inputText` 引号回退同步、Sparkle 首次点击检查更新的竞态以及词库页音节数动态统计。

### 2.0.0 大版本升级：统计语言模型整句、中英混输、U 模式拆字、百宝箱与文件夹双向同步

- **统计语言模型与整句引擎重构**：引入本机 LM / Bigram Lattice 整句解码与核心词库/多音字重排，彻底移除笛卡尔积伪短语拼接，显著降权生僻/古音读法并克制 Emoji 候选穿插（仅在适当时机插入且不抢占高频常用词首选）；模糊音默认改为关闭，避免误匹配干扰。
- **英文单词与中英混输**：内置本机英文词库，支持纯英文单词联想与中英混合无缝输入，保留大小写与常用技术词直出。
- **双拼同音候选穿插**：优化小鹤、微软、自然码与搜狗双拼在多音节同音编码下的候选排序与穿插展示，兼顾高频词组与同音次选。
- **U 模式部件拆字（`u`）**：输入 `u` 加部件拼音即可拆字反查生僻字与汉字读音（如 `umumumu → 森`、`uriyue → 明`）。
- **URL/邮箱智能标点与成对符号自动补全**：自动识别网址、邮箱与版本号等上下文抑制中文标点转换；支持括号与引号成对自动补全，紧接按 `Backspace` 一键成对删除。
- **高频快捷键与选词交互**：新增可选 `,` / `.` 候选翻页、`[` / `]` 以词定字（取当前候选首字/尾字）与 `;` 快速选第二候选；支持左/右 `Shift`、大小写锁定（`Caps Lock`）以及切换英文时的缓冲区处理动作配置。
- **快捷短语、隐私过滤剪贴板历史与百宝箱面板**：新增全局百宝箱面板（`⌃⇧V` 剪贴板历史、`⌃⇧E` 快捷短语/表情，或在输入流中使用 `vjb` / `vcy` / `vbq` 呼出），剪贴板历史支持密码管理器与隐私来源过滤，支持常用短语模板一键上屏。
- **本地 / iCloud 文件夹双向同步**：支持将个人词库、自定义短语、置顶/忽略记录与配置与指定本地目录或 iCloud Drive 文件夹双向自动同步，无账号依赖即可在多台 Mac 间安全共享词库。

### 系统输入法菜单稳定性与安装体验修复（2.0.1）

- **杜绝覆盖升级、重复安装或卸载重装后从菜单栏消失**：新增 `InputMethodRegistrar` 安装包路径与 inode 指纹监测机制；无论是通过安装向导覆盖安装、卸载重装还是通过 Sparkle 应用内升级，在初始化 `IMKServer` 前自动清理隔离属性、刷新 LaunchServices / `IntlFileCache` 并重启持有旧版文件描述符的 `imklaunchagent`、`TextInputSwitcher`、`TextInputMenuAgent`，同步完成 Carbon `TIS` 重注册与重启用循环。
- **修复 macOS 27 `InputMethodConnectionName` 校验拒绝报错**：将 `Info.plist` 与 `main.swift` 的连接名统一为符合系统校验规范的 `com.aethernative.inputmethod.AetherKey_Connection`，消除首次切换进入应用时的 `Request for Endpoint Invalid` 报错。
- **安装向导支持安全卸载、重复安装与一键修复**：`安装 AetherKey.app` 新增保留用户词库与偏好的「卸载 AetherKey」确认操作、安装前自动切离当前会话并清理孤立进程，以及「刷新系统输入法菜单」修复入口。
- **菜单栏与设置自愈入口**：通用设置新增「在菜单栏常驻 AetherKey 快捷图标」开关；输入法菜单、独立状态栏菜单与「更新与启动」设置页均提供「刷新系统输入法菜单」按钮。


### 安装指纹持久化与自动切换稳定性修复（2.0.2）

- 修复主程序内 `UserDefaults(suiteName:)` 与当前 `CFBundleIdentifier` 相同返回 `nil` 导致安装包指纹未持久化、日常重启误触发系统输入法进程刷新的问题，并延长 `TIS` 启用后的自动切入等待窗口，保证安装/升级后直接自动切回 `AetherKey 拼音`。
